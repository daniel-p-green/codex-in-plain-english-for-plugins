Lesson 2

Write the starter prompt.

A strong helper request names the outcome, the source, the boundary, the deliverable, and the proof you expect.

Write the starter prompt

Plain-English rule

Tell Codex the outcome and the boundary. Do not lead with a tool name unless the tool matters.

Verification rule

Every helper prompt should say what proof you expect before Codex calls the work done.

Strong helper prompts include

  • Goal
  • Context source
  • Boundary
  • Deliverable
  • Proof
  • Stop condition
