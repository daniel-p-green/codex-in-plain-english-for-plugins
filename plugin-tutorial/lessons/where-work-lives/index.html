Lesson 4

Know where the work lives.

Helpers make more sense when you map them to the place the work lives: meetings, files, websites, data, or creative outputs.

Know where the work lives

Daily context

Slack, Gmail, Calendar, Drive, Granola, and Zoom help Codex find the surrounding conversation before drafting or summarizing.

Use for meetings, events, follow-up →

Build and verify

Browser, GitHub, and Computer Use help Codex inspect a visible page, a project, or a desktop app and prove what changed.

Use for websites and app work →

Artifacts

Documents, Spreadsheets, Presentations, Data Analytics, and Product Design turn work into reviewable outputs.

Use for docs, dashboards, prototypes →

Creative output

Creative Production, Canva, Figma, Fal, Adobe, Remotion, HyperFrames, and HeyGen help make public-facing assets.

Use for image, video, and social work →

What proof should Codex show?

Kind of work Good proof Weak proof
Meetings and events Meeting titles, source notes, draft follow-up, missing access A confident summary with no source boundary
Websites and apps File links, test output, route check, screenshot "It should work now"
Creative output Variants, selected direction, export path, claim notes A pretty asset with unsupported claims
Numbers and reports Source rows, metric definition, caveats, chart artifact A chart with no denominator or source
