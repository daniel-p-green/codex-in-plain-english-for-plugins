ChatGPT sign-in, in plain English

This public course does not log you in by itself.

There is a Codex app-server lane that can start ChatGPT login for a Codex client or harness. This page is different: it is a public GitHub Pages course. It teaches the pattern, then sends real account work back to Codex, ChatGPT, or a proper app/server.

Public website

No account access

Good for learning the pattern, choosing a helper, and copying starter prompts.

Codex app-server

Can start ChatGPT login

Good for a Codex client or harness. It can hand the client a sign-in link or device-code flow.

GitHub Pages boundary

Cannot run that server

A static page cannot safely own OAuth callbacks, secrets, tokens, or sessions by itself.

Real app lane

Separate product work

If this becomes a real app, build the server, permission flow, and safety checks as their own surface.

The important distinction: You were right: one Codex app-server path can log in with ChatGPT. The plain-English course should still avoid a fake login button, because a public static page is not the app-server and should not pretend to be.
